# capital-mett.com

Статический сайт на Astro. Цены приходят из Excel-файла на Яндекс Диске, сайт пересобирается и выкладывается на хостинг через GitHub Actions.

## Команды

- `npm install` — установить зависимости
- `npm run dev` — открыть сайт на своём компьютере
- `npm run build` — собрать сайт в папку `dist/`
- `PRICES_FILE="docs/Цены Капитал Метт.xlsx" npm run prices` — проверить Excel-файл и обновить цены

## Как обновляются цены

1. Сотрудник меняет цену в файле «Цены Капитал Метт.xlsx» на Яндекс Диске и сохраняет.
2. Каждые 15 минут GitHub Actions скачивает файл по публичной ссылке (`scripts/fetch-prices.mjs`). GitHub иногда запускает проверку с опозданием на 5–20 минут, так что новые цены появляются на сайте примерно через 15–40 минут после сохранения.
3. Если таблица в порядке и цены изменились, новые цены записываются в `src/data/prices.json`, сайт пересобирается и выкладывается: превью на GitHub Pages и хостинг (когда он настроен). Меняются цены везде — прайс на главной, калькулятор, страницы площадок. Дата «Цены на …» ставится сама.
4. Если в таблице ошибка, сайт остаётся со старыми ценами, запуск помечается как неудачный, GitHub присылает письмо (пока ошибку не исправят — при каждой проверке). В журнале запуска написано, какую строку исправить.
5. Обновить цены сразу, не дожидаясь проверки: Actions → «Сайт и цены» → Run workflow.

Что считается ошибкой: изменённые названия столбцов, пустая или текстовая цена, единица не «₽/кг» и не «₽/т», повтор позиции, «да» в «На главной» не у 2–3 позиций, меньше 10 строк, цена изменилась больше чем в 3 раза (защита от опечатки; обходится галочкой при ручном запуске).

Как сотрудникам править файл, чтобы ссылка не сломалась:
- открывать файл прямо на Яндекс Диске (откроется в Яндекс Документах) или через приложение Яндекс Диска на компьютере и сохранять поверх;
- не удалять файл и не загружать вместо него новый с другим именем — у нового файла будет другая ссылка;
- не переименовывать столбцы и лист «Цены»; новые позиции добавлять строками внизу или внутри своей категории.

Если позиция новая и её нужно показать коротким названием (например, на первом экране), добавьте его в `shortNames` в `src/data/calculator.json`.

GitHub отключает расписание в публичном репозитории, если в нём 60 дней не было ни одного изменения. Каждая смена цен — это изменение, так что при живом прайсе это не грозит; если всё же отключилось, Actions → «Сайт и цены» → Enable workflow.

## Настройка GitHub (один раз)

Settings → Secrets and variables → Actions → Secrets:

| Секрет | Что это |
| --- | --- |
| `PRICES_URL` | публичная ссылка на Excel-файл на Яндекс Диске (вида `https://disk.yandex.ru/i/…`); без неё сайт работает на ценах из `prices.json` |
| `SSH_HOST` | адрес сервера хостинга |
| `SSH_USER` | логин SSH |
| `SSH_KEY` | закрытый SSH-ключ (открытый добавлен в панели хостинга) |
| `SSH_PORT` | порт SSH, если не 22 |
| `DEPLOY_PATH` | папка сайта на хостинге, например `~/test.capital-mett.com/public_html` |

Variables: `SITE_NOINDEX` = `1`, пока сайт лежит на тестовом адресе (закрывает его от поисковиков). Перед переключением домена удалить.

## Где что лежит

- `src/data/prices.json` — текущие цены (меняет автоматика)
- `src/components/PriceList.astro` — полный прайс по категориям: на главной (выше площадок) и на страницах площадок
- `scripts/read-xlsx.mjs` — чтение Excel; понимает файлы, сохранённые в Excel, Яндекс Документах, LibreOffice, Р7, МойОфис и Google Таблицах
- `src/data/yards.json` — площадки; страница площадки появляется, когда заполнен блок `page`. Поля блока: `inCity` («в Щёлкове»), `street` (в заголовке вкладки), `where` — только если в городе несколько площадок («на Южной»), `pickup` (зона вывоза), `near` (три соседние площадки), `howToFind` (как проехать; пока `null` — в превью видна пометка), `photos` (подписи заглушек фото)
- `src/data/services.json` — страницы услуг: тексты, метатеги, порядок блоков, вопросы и ответы; карточки услуг на главной берутся отсюда же
- `src/data/fleet.json` — техника: характеристики и цена смены (нужна на всех страницах услуг)
- `src/data/steps.json` — пять шагов «Как мы работаем»
- `src/pages/uslugi/[slug].astro` — общий шаблон страниц услуг
- `src/pages/sitemap.xml.ts` — карта сайта, собирается сама
- `src/data/site.json` — телефоны, мессенджеры, вакансии, реквизиты
- `src/data/calculator.json` — проценты засора и правила калькулятора
- `public/.htaccess` — адреса без `.html`, позже 301-редиректы
- `.github/workflows/site.yml` — сборка, цены и выкладка
- `.github/workflows/pages.yml` — превью на GitHub Pages (с Яндекс Картой), закрыто от поисковиков

## Страницы услуг

Три страницы (`/uslugi/samovyvoz`, `/uslugi/demontazh-metallokonstruktsij`, `/uslugi/arenda-tekhniki-i-oborudovaniya`) собираются из одного шаблона. Чтобы поменять текст, откройте `src/data/services.json`; чтобы поменять грузоподъёмность, кузов или цену смены — `src/data/fleet.json`.

Заглушки: `"value": null` в `fleet.json` показывает на странице «уточняется»; `"check"` и `"todo"` — пометки для владельца, видны только в превью. Когда цены аренды подтверждены, поставьте `"pricesConfirmed": true`. Фото машины: положите файл в `public/images/` и впишите путь в `"photo"`.

Цели Метрики для заявок: общая `form` и по странице — `form-samovyvoz`, `form-demontazh`, `form-arenda`.

## Превью

Каждая страница превью публикуется отдельно: HTML-файл страницы как `index.html` плюс папка `dist/assets/`. Чтобы ссылки между страницами превью работали, адреса передаются при сборке:

```
PUBLIC_MAIN_URL=… PUBLIC_ISTRA_URL=… PUBLIC_SAMOVYVOZ_URL=… PUBLIC_DEMONTAZH_URL=… PUBLIC_ARENDA_URL=… npm run build:preview
```

## Яндекс Карта площадок

На главной в блоке «7 площадок» — настоящая Яндекс Карта (JavaScript API 2.1, бесплатная версия). Ключ — `ymapsKey` в `src/data/site.json`. Метки берутся из `src/data/yards.json`: `lat`, `lon` — координаты, `yandex` — ссылка на карточку площадки в Яндекс Картах (в окне метки появится «Отзывы в Яндекс Картах»).

Скрипт Яндекса грузится, только когда посетитель долистал до блока. Если карта не загрузилась, остаётся схема. В превью Claude карта не грузится никогда — там всегда схема.

Условия бесплатной версии: логотип Яндекса, копирайты и кнопку «Открыть в Картах» не перекрывать и не скрывать.

## Превью на GitHub Pages

Пока сайт не на хостинге, его можно смотреть по адресу `https://vvolovik19-byte.github.io/capital-mett-site/` — там работает и Яндекс Карта (в превью Claude она не загружается). Превью собирается само при каждой правке в `main` и после каждой смены цен в Excel.

Включить один раз: Settings → Pages → Build and deployment → Source: **GitHub Actions**, затем Actions → «Превью на GitHub Pages» → Run workflow. На бесплатном тарифе GitHub Pages работают только для публичных репозиториев. Превью закрыто от поисковиков. Страниц, которые ещё не сделаны (список площадок `/punkty-priema`, «О компании», политика), там нет — по ссылкам на них будет 404.
